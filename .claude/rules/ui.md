  - ✗ `useEffect(() => setHover(null), [labels.length, layers.length])` + 渲染期 `hover < n` clamp —— **不管用**。三条独立原因（codex 复核确认）：① React 复用同一实例，旧 `hover` 直接活进新数据集；② `hover` 只是个数字、不带「我属于哪一档」，切档后同一索引往往**仍在范围内**，clamp 放行——clamp 防越界，不防**语义过期**；③ `labels.length` 不是数据集 identity（不同档位可能等长、连点会跳过中间长度），且 effect 在 commit 之后才跑，新数据至少先用旧 `hover` 画一帧，排队中的旧 `mousemove` 还会写回同一个 state。
  - 反向对照实测（2026-08-09，harness 驱动 mousemove → 点 7d → 点 30d，**不发 mouseleave**）：去掉 `key` 时浮层钉在旧索引不走，30d 视图下显示 `2026-07-20`——一个从未 hover 过的日期；加回 `key` 后浮层与参考线一并消失。截图 `~/Downloads/codexbar_traffic_verify_20260809/Q_{A,B,C}_*.png`。
  - 一般规则：**只要一个组件里存着「某数据集内的索引/位置」这类 state，换数据集就用 `key` 卸载重建，别在组件内部打补丁。**

## 5c. ★★ 页面统一性（用户 2026-09-09 拍板，反复提过）

**同一类页面必须长得一样。** 「平台详情」有 8 个平台共用一个 `PlatformPage`，
「AI用量信息 / 中转站·用量」是同一族的两页 —— 读者在它们之间来回切，
每多一种**只在某一页出现**的版块，就多一次"这一页为什么不一样"的认知成本。

### 动手前先回答

1. **这块内容其余同类页面有吗？** 没有 ⇒ 默认**不加**。
2. **它属于这一页的主题吗？** 用量页讲的是 **token 与钱**；
   **账号额度不属于用量页** —— 它是账号的属性，家在总览的额度卡。
   （2026-09-09 实测踩到：agy 详情页挂着 `gemini-5h / gemini-weekly` 两条额度水位条，
   其余 7 个平台都没有，用户第一反应是「为什么账号额度在这里显示？？」。）
3. **它会长期有用，还是只是某次改动的临时免责？**
   临时免责会**过期成噪音**：agy 的覆盖率横幅在覆盖率 16% 时是必要的，
   接上原生 SQLite 升到 ~95% 之后就只剩占地方，用户直接说「删掉吧，没用了」。
4. **它值不值得常驻？** 一天看一次的信息 ⇒ **折叠进角标，悬浮才展开**
   （`.cb-hoverwrap` / `.cb-hoverpop`，见 `App.css`）。
   已这么处理的：codex 详情页的「路由分账」四行明细 + 费用免责。

### 两条硬约束

- ★★ **折叠一律用 CSS 控制可见性，不用条件渲染。** 条件渲染会让内容离开 DOM，
  而本仓的行为闸都在 `--dump-dom` 的静态 DOM 上断言 —— 一改就**全部静默失效**
  （"测试还在、但什么也没验"，本仓记过的空守卫形态）。
- ★ **删版块就连组件本体一起删**，不留骨架。留一份没人渲染的组件，
  下一个人会以为它还在页面上。要恢复请从 git 历史取。

### 已删除的，别"顺手"加回来

| 位置 | 删的东西 | 理由 |
|---|---|---|
| `PlatformPage`（agy） | 覆盖率横幅 `覆盖 277/303 …` | 覆盖率升到 ~95% 后退化成噪音 |

## 5d. 组件级设计规范（2026-09-09 定稿，全是被用户打回后确定的）

全局设计语言在 `~/.claude/rules/ui-design.md`（自动加载）。这一节只记**本仓特有的、
被真实反馈校准过的组件行为**——写在这里是因为它们每一条都对应一次返工。

### 互斥单选（路由选择器 / 档位 / 页内版块切换）

- **一律用 `Seg`**，或与它同形：带边框的容器 + 内部 gap 2~3。
  形状本身就说明"这几个里挑一个"；散开的独立按钮读起来像"几个动作"。
- ★★ **选中 = 实心填充 + 反白文字 + 加粗**；未选中一律透明。
  用户 2026-09-09 反馈「中转站的选择池，不够明显」——当时选中只是"淡背景 + accent 描边"，
  与未选中的描边 chip 差别太小。**而这是全 app 唯一一个会改变钱去哪儿的选择器。**
- **accent（品牌青）专属"当前生效"这一个含义**。同一个单选组里混两种填充色，
  反而读不出谁是选中。琥珀留给**钱**：未选中的付费档用琥珀描边 + `💰按量付费`，
  以及点下去后的二次确认。

### 折叠与浮层

- 一天看一次的信息 ⇒ 折叠进角标，悬浮才展开（`.cb-hoverwrap` / `.cb-hoverpop`，见 `App.css`）。
  已这么处理：codex 详情页的「路由分账」。角标**紧挨它解释的东西**（源路径旁边），
  单独占一行会把 KPI 往下推、且看着像一条告警。
- ★★ **折叠一律用 CSS 控制可见性，不用条件渲染**（理由见 §5c）。
- 浮层必须 `position: absolute` + `pointer-events: none`；宽度用 `maxWidth: min(Npx, 60vw)`
  防窄窗顶出容器。**并把 `.cb-hoverpop` 排除在 harness 的 overflow 探针之外** ——
  绝对定位层会计进父元素 `scrollWidth`，那不是"内容装不下"而是这个设计的定义。

### 数字与表格

- 数字一律 `NUM`（等宽 + `tabular-nums` + **`whiteSpace: nowrap`**）。断字在本仓算 bug。
- ★ **同一行里所有单元格用同一份纵向 padding**。只给第一格加 padding 会把行撑高、
  其余格子被拉满 ⇒ harness 的折行探针（比"内容盒高 vs 行高"）把它们**全判成折行**
  （实测 10 处假阳性）。真折行会淹在假阳性里。
- **读不到显 `—`，不显 `0`**：两者的下一步动作完全相反。

### 图表

- **两个量纲永不同图**（token vs 钱）。钱进 tooltip 标题与 KPI 条，不占第二个 y 轴。
- 堆叠图**占比大的贴基线**；细带夹在中间会来回跳。
- 图的 `key` 必须带**数据集身份 + 档位 + 分层维度**：hover 是"某个数据集里的索引"，
  换任何一维都必须让实例作废。
- 同一个模型在不同页面**用同一个颜色**：一律走 `modelColor()`，别各自哈希。
- **档位不够时说出来**（"中转站只给了 3 天，不足 14 天"）——
  否则 3 根柱子会被读成"这 14 天就用了这么点"。
- 同一页上**两个数不同窗口必须写出来**（模型表若不跟档位走，标题旁边就要写明）。
  这条在 scan 侧栽过一次（119M vs 9,004M）。

### 披露

- 告警/免责放在**眼睛已经在的地方**，且文本要说"做什么"不是只说"坏了"。
- **披露的寿命跟着它描述的事实走**：覆盖率横幅在 16% 时必要，到 ~95% 就是噪音，该删。
- **换了数据源，页面上的话必须跟着换**。「后端有字段 ≠ 已披露」有个反向形态：
  **后端改了、披露层还在说旧事实**——那是一句关于事实的假陈述，而且正好会让用户
  以为"还是没接上"。闸：`tests/test_agy_sqlite.py::TheFrontendCopyMatchesTheBackend`。
